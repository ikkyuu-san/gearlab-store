# Demo product imagery

These images are product placeholders, not GearLab brand assets or actual supplier photographs. They were created with the built-in image-generation tool before the branding clarification. No additional brand or logo generation was performed. Cards and the hero label them as demo imagery.

Saved assets: `demo-setup.png`, `demo-keyboard.png`, `demo-mouse.png`, and `demo-audio.png`. The desk-accessories slot intentionally uses a photo-coming-soon placeholder. Replace these images with verified real photographs when products are added.

## Prompt set

All four prompts begin with:

> Use case: product-mockup. Asset for a premium GearLab e-commerce website, placeholder concept imagery. Photorealistic studio product photography, strictly achromatic black charcoal gray and white. Matte materials with restrained silver highlights and realistic soft shadows. No RGB, neon, colors, smoke, slogans, watermarks or logos.

Dark seamless charcoal studio background. Professional high-end tech catalog photograph. No computer or screens.
